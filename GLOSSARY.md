# Zipline API node

An n8n community node that drives a self-hosted Zipline file host: uploading, listing, changing and downloading the authenticated user's files, and reading the instance's status.

## Language

**File list**:
The authenticated user's files as Zipline hands them out: in numbered pages of at most 100, narrowed by search, folder, favorite and media filters, in a chosen sort order.
_Avoid_: file search, file query, file listing
